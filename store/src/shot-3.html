Lang Lock

Works before the page loads

The server gets your language in the first request. Page scripts see it from their first line.

Request headers

Accept-Language: pl-PL,pl;q=0.9
Accept-Language: en-US,en;q=0.9

Console

> navigator.language
  'en-US'
> navigator.languages
  ['en-US', 'en']
1. Requestheader is set
2. document_startnavigator is set
3. Page scriptssee your language
